# Interchange (전자음악 노선도) 사이트

게임 화면(`public/index.html`)과, 계정·기록 저장을 맡는 작은 서버(`server/`)로 이루어져 있습니다.
**서버 없이 화면만 올려도** 게임과 유튜브 영상은 열립니다. 이때 계정은 그 브라우저 안에만 저장됩니다.
서버까지 올리면 아이디와 비밀번호로 로그인하고, 다른 기기에서도 기록이 이어지고, 개발자가 고친 내용이 모두에게 보입니다.

## 왜 웹사이트로 올려야 하나

유튜브 영상은 "주소가 있는 웹사이트"에서만 열립니다. 파일을 더블클릭해서 열면(`file://`) 영상 창이 오류를 냅니다.
Claude의 미리보기 화면에서도 영상 삽입이 막혀 있습니다. 아래 방법 중 하나로 올리면 됩니다.

## 방법 1. 화면만 올리기 (가장 쉬움, 로그인은 이 브라우저에만 저장)

`public` 폴더의 내용(`index.html`, `three.min.js`, `_headers`)만 올립니다. 아래 서비스 중 아무거나 됩니다.

- **Cloudflare Pages**의 직접 업로드, **Netlify**의 폴더 끌어 놓기 업로드
- **GitHub Pages**: 저장소에 `public` 안의 파일을 올리고 Pages를 켭니다.

올린 주소(예: `https://내이름.pages.dev`)로 들어가 영상이 열리는지 확인하세요.

## 방법 2. 서버까지 올리기 (Cloudflare Pages + KV, 무료 한도 안에서 가능)

1. 이 폴더 전체를 GitHub 저장소에 올립니다(`.gitignore`는 그대로 두세요).
2. Cloudflare에 가입한 뒤 Workers & Pages에서 **Pages 프로젝트를 만들고 GitHub 저장소를 연결**합니다.
   - Framework preset: `None`
   - Build command: 비워 둠
   - **Build output directory: `public`**
   - `functions` 폴더는 Cloudflare가 저장소 맨 위에서 알아서 찾습니다. 직접 업로드로는 `functions`가 올라가지 않을 수 있으니 Git 연결을 쓰세요.
3. Workers KV에서 네임스페이스를 하나 만듭니다(이름은 아무거나, 예: `interchange`).
4. 만든 Pages 프로젝트의 Settings에서 **Bindings → Add → KV namespace**로, 변수 이름은 정확히 **`KV`**, 값은 방금 만든 네임스페이스를 고릅니다.
5. 같은 Settings의 **Variables(환경 변수)** 에 아래 세 개를 넣습니다. 비밀 값은 "Encrypt/Secret"로 저장하세요.

   | 이름 | 값 |
   | --- | --- |
   | `SECRET` | 아무도 모르는 긴 글자(32자 이상). 로그인 표를 서명하는 데 씁니다. 바꾸면 모두 로그아웃됩니다. |
   | `DEV_IDS` | `dev.KSJ` (개발자 대표 아이디. 쉼표로 여러 개 가능) |
   | `DEV_SETUP_CODE` | 대표 아이디를 처음 만들 때 한 번 쓰는 비밀 코드 |

6. 설정을 바꿨으면 **다시 배포**합니다(Deployments에서 Retry deployment 또는 저장소에 작은 변경을 올림).
7. 사이트에 들어가 시작 화면의 아이디에 `dev.KSJ`를 적고 비밀번호와 **설정 코드**를 넣어 계정을 만듭니다. 이 코드가 없으면 아무도 대표 아이디를 가로챌 수 없습니다.
8. 만든 뒤에는 `DEV_SETUP_CODE` 변수를 지워도 됩니다(지우면 대표 아이디를 새로 만들 수 없게 됩니다).

시작 화면 아래에 "기록은 서버에 저장되어 다른 기기에서도 이어집니다."라고 나오면 서버가 연결된 것입니다.
"서버가 없는 환경이라 기록은 이 브라우저에만 저장됩니다."라고 나오면 KV 연결이나 환경 변수가 빠진 것입니다.

## 방법 3. 내 컴퓨터나 일반 서버에서 돌리기

Node 18 이상이 필요합니다.

```
DEV_IDS=dev.KSJ DEV_SETUP_CODE=아무코드 node server/node.js
```

`http://localhost:8787`로 들어갑니다. 기록은 `data.json`, 비밀 값은 `secret.txt`(자동 생성)에 저장됩니다.
이 두 파일은 `.gitignore`에 들어 있으니 저장소에 올리지 마세요. 인터넷에 공개하려면 서버에 https를 붙여야 합니다.

## 기능이 하는 일

- **로그인**: 아이디(2~20자)와 비밀번호(8자 이상). 비밀번호는 서버에 PBKDF2로 변환해 저장하고, 브라우저에는 저장하지 않습니다.
- **기록 저장**: 게임 기록이 바뀌면 몇 초 뒤 서버에 저장합니다. 다른 기기에서 먼저 저장했으면 두 기록을 합칩니다(방문과 도전과제는 합집합, 경험치 같은 숫자는 큰 쪽).
- **개발자 편집 공유**: 개발자 계정이 표(스프레드시트 창)에서 고친 뒤 **모두에게 반영**을 누르면 모든 사람에게 보입니다.
- **권한 관리**: 대표 계정만 다른 계정에 개발자 권한을 주고 거둘 수 있고, 비밀번호를 잊은 계정의 비밀번호를 다시 정해 줄 수 있습니다.
- **로그인 시도 제한**: 틀린 로그인이 쌓이면 15분 동안 잠깁니다.

## 꾸미기와 도전과제

- 상점의 사진 배경 4종(어두운 성운, 청록 입자 물결, 흑백 행성과 소행성대, 블랙홀), 이미지 행성 지점 2종, 조준점 아이콘 10종은 `public/index.html` 안에 그림이 들어 있습니다. 가격은 코드의 `SHOP` 목록 한 곳에서 바꿉니다.
- 도전과제는 위쪽 메뉴의 "도전과제"(키보드 Y)에서 영역별로 보고, 달성한 것은 "받기"나 "모두 받기"를 눌러야 토큰이 들어옵니다. 보상 숫자는 코드의 `ACHR` 표에 있습니다.
- 이미 도전과제를 달성해 토큰을 쓴 기록은, 처음 열 때 받은 것으로 처리되어 토큰이 줄지 않습니다.

## 공개하기 전에 손볼 곳

- **운영자 연락처**: `public/index.html`에서 `window.INTERCHANGE_CONTACT=''`를 찾아 따옴표 안에 연락처(이메일 등)를 적으세요. 개인정보 안내 창의 "문의" 줄에 나옵니다. 비워 두면 "운영자 연락처는 아직 적혀 있지 않습니다"라고 나옵니다.
- **공유 미리보기 그림**: `public/og.png`가 링크를 공유할 때 나오는 그림입니다. 일부 서비스는 상대 주소를 읽지 못하니, 주소가 정해지면 `index.html`의 `og:image`를 `https://내주소/og.png`처럼 전체 주소로 바꾸세요.
- **아이콘**: 탭에 보이는 아이콘은 `index.html` 안에 들어 있고, 휴대폰 홈 화면용은 `public/apple-touch-icon.png`입니다. 바꾸려면 두 곳을 같이 고치세요.
- **개인정보 안내문**은 이 사이트가 실제로 저장하는 것(아이디, 변환한 비밀번호, 게임 기록, 보낸 의견)을 있는 그대로 적은 안내입니다. 법률 검토를 거친 방침이 아니므로, 공개 범위에 따라 필요한 절차(예: 만 14세 미만 이용자)를 직접 확인하세요.

## 의견·오류 보내기

시작 화면과 설정 창의 "의견·오류 보내기"로 받은 글은 서버에 저장됩니다(최근 300개). 대표 계정(`DEV_IDS`)으로 로그인하면 설정 창의 "받은 의견"에서 읽고 지울 수 있습니다. 한 접속 주소가 한 시간에 5번까지만 보낼 수 있습니다. 서버가 없는 환경에서는 "내용 복사"로 글을 복사해 직접 전달하게 됩니다.

## 로그인이 안정적으로 이어지는 방식

- 로그인 표는 30일 유효하고, 사이트를 열 때 남은 기간이 절반 아래이면 새 표로 바뀝니다. 쓰는 동안은 로그인이 이어집니다.
- 틀린 비밀번호는 같은 접속 주소에서 한 아이디에 8번까지입니다. 그 뒤 15분 동안은 그 접속 주소에서만 막혀서, 다른 사람이 일부러 내 계정을 잠글 수 없습니다. 접속 주소를 바꿔 가며 한 아이디를 계속 시도하면(30번) 그 아이디 전체가 15분 동안 막힙니다.
- 서버가 15초 안에 대답하지 않거나 연결이 끊기면, 화면에 이유가 나오고 단추가 다시 눌립니다. 로그인 단추를 연달아 눌러도 요청은 한 번만 갑니다.
- 처음 접속할 때 서버를 못 찾으면 2초, 5초, 12초 뒤에 다시 찾습니다. 기기가 다시 온라인이 되면 기록 저장도 다시 시도합니다.
- 서버가 로그인 표를 거부하면 이 브라우저의 기록은 그대로 두고, 시작 화면에서 다시 로그인하라고 안내합니다. 같은 아이디로 다시 로그인하면 이 브라우저의 기록과 서버 기록이 합쳐집니다.

## 알아 둘 점

- **비밀번호 복구 이메일이 없습니다.** 잊으면 대표 계정이 새 비밀번호를 정해 줘야 합니다.
- 로그인 표는 브라우저의 localStorage에 저장됩니다. 공용 컴퓨터에서는 쓴 뒤 꼭 로그아웃하세요.
- Cloudflare KV는 지역에 따라 저장한 값이 다른 곳에서 보이기까지 최대 1분쯤 걸릴 수 있습니다.
- 기록 한 건은 300KB, 개발자 편집 전체는 2MB까지 저장됩니다.
- 시험: `node tests/api.test.mjs` (서버 규칙 66개를 확인합니다).
